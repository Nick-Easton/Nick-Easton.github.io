从零开始搭建
我的个人博客

记录这个博客从简单样板到个人数字空间的第一阶段。

2026 年 7 月 12 日 阅读约 6 分钟 Nick

一直以来，我都希望拥有一个真正属于自己的网络空间。它不只是展示信息的名片，也可以保存学习过程、项目经验和生活里的灵感。于是，这个博客成为了我的第一个长期网站项目。

为什么要搭建个人博客？

社交平台适合分享当下，但内容很容易被时间线淹没。个人博客则更像一座自己维护的图书馆：页面如何组织、文章如何呈现、哪些内容值得留下，都可以由自己决定。

我希望这里既是一份成长档案，也是一块可以持续试验新技术的地方。

目前我正在学习嵌入式开发，同时也开始接触 HTML、CSS 和 JavaScript。亲手完成一个博客，可以把零散知识组合成真实作品。

第一阶段的技术选择

博客当前采用最基础的静态网页方案，主要由三个部分组成：

  • HTML：定义页面的内容与结构。
  • CSS：负责布局、颜色、动画和响应式设计。
  • JavaScript：实现文章数据、搜索和阅读交互。

这种方案没有复杂的构建流程，很适合用来理解浏览器如何加载和呈现网页。例如，一张最简单的文章卡片可以这样组织：

<article class="post-card">
    <h2>文章标题</h2>
    <p>文章简介</p>
    <a href="文章地址">继续阅读</a>
</article>

从样板到真正的首页

最初的页面只有背景、头像卡片和顶部导航。它已经具备个人风格，但还无法承担博客首页的任务。新的首页增加了欢迎区、个人简介、最新文章、最近项目和快捷入口。

视觉上继续保留我喜欢的动漫背景，同时使用深色内容区和半透明卡片，让图片负责营造氛围，让文字区域保持清晰。页面也针对手机屏幕重新排列，避免只能在电脑上正常浏览。

.content-card {
    background: rgba(255, 255, 255, 0.08);
    border: 1px solid rgba(255, 255, 255, 0.12);
    backdrop-filter: blur(18px);
}

用 Git 保存每一个阶段

博客文件保存在电脑上，Git 负责记录每一次有意义的修改，GitHub 则保存远程副本并用于发布网站。以后一次完整更新通常会经历：

git status
git add .
git commit -m "新增一篇博客文章"
git push

这样做的好处是，即使某次修改出现问题，也可以找到之前稳定的版本，而不需要创建很多“最终版”文件夹。

接下来准备做什么？

第一篇文章只是起点。接下来我计划逐渐补充这些内容：

  • 整理嵌入式学习笔记和实验记录。
  • 展示正在完成的个人项目。
  • 增加摄影、游戏和生活随笔。
  • 继续完善主题切换、评论和网站性能。

博客不需要一次变得完美。比起追求一个永远无法完成的最终版本，我更希望它随着学习一起慢慢成长。
